# WASPADA PHISHING — BLOG SOCIAL CAMPAIGN

Proyek website/blog kampanye sosial untuk mata kuliah Aplikasi Teknologi & Transformasi Digital.

## Isi paket
- `index.html`: halaman utama, navigasi, rekomendasi artikel, kuis, dan bantuan.
- `apa-itu-phishing.html`: pengertian dan modus phishing.
- `ciri-ciri-phishing.html`: 7 ciri pesan phishing.
- `jika-terlanjur-klik.html`: langkah tanggap insiden.
- `tentang.html`: tujuan kampanye.
- `assets/styles.css`: desain responsif untuk desktop dan HP.
- `assets/script.js`: navigasi HP dan kuis 3 pertanyaan (tidak menyimpan data).

## Melihat website secara offline
1. Ekstrak ZIP.
2. Klik dua kali `index.html` untuk membukanya di browser.
3. Klik menu Artikel, Kuis, dan Tentang untuk mencoba semua fitur.

## Menerbitkan gratis di GitHub Pages
1. Login/daftar di https://github.com/.
2. Buat repository baru, misalnya `waspada-phishing` (pilih Public).
3. Upload seluruh file dan folder dalam ZIP (JANGAN hanya file ZIP).
4. Buka Settings > Pages. Pada Build and deployment, pilih Deploy from a branch; Branch `main`, folder `/(root)`, lalu Save.
5. GitHub akan menampilkan alamat publik di halaman Pages ketika penerbitan selesai.
6. Pengunjung dapat membuka blog itu dari HP lewat tautan publik.

## Jika harus memakai WordPress.com gratis
WordPress.com gratis membatasi script JavaScript dan style CSS kustom di blok HTML. Karena itu, jangan tempel SELURUH `index.html` ke blok Custom HTML dan berharap tampil sama. Sebagai gantinya:
- Gunakan WordPress editor bawaan untuk membuat halaman dan pos.
- Salin teks artikel dari halaman web yang telah disiapkan, serta gunakan blok standar Heading, Paragraph, Buttons, dan Cover.
- Kuis di website HTML/JS ini bisa ditautkan dari WordPress melalui tombol/link setelah diterbitkan di GitHub Pages.
- Atau pakai WordPress ber-hosting dengan kemampuan kode kustom jika ingin menerapkan desain penuh di WordPress.

Dokumentasi WordPress resmi: https://wordpress.com/support/code/
